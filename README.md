## 🧭 How to use this repository

1. Find your lab in the tables below and open its folder.
2. Pick the approach that suits you. Most labs offer three:

| File | Approach | Best for |
|---|---|---|
| `Pro/GUI-Solution.md` | Step-by-step in the Google Cloud console | Learning the concepts |
| `Pro/CLI-Solution.md` | `gcloud`, `gsutil` and `bq` commands in Cloud Shell | Speed and repeatability |
| `Pro/Automation-Solution.md` | Scripts and infrastructure as code | DevOps practice |
| `Challenge-Lab-specific-solution.md` | The shortest path through the lab | A quick reference |

3. Replace placeholder values with the ones from **your** lab instructions. Names, regions and zones change per session.

> 💡 Attempt the lab yourself first. Use these solutions to get unstuck or to compare approaches.

## 🤝 Contributing

Contributions are welcome, from new solutions and fixes for outdated steps to clearer explanations.

1. Fork the repository and create a branch: `git checkout -b add/<lab-id>`.
2. Start from a file in [`templates/`](./templates/).
3. Open a pull request that describes the lab and what you changed.

See [CONTRIBUTING.md](./CONTRIBUTING.md) for details. Found a broken step? [Open an issue](https://github.com/codewithgarry/Google-Cloud-Challenge-Lab-Solutions-Latest/issues).
